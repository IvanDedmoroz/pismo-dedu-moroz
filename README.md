# Письмо Деду Морозу — локальная версия

Приложение работает на компьютере владельца и хранит данные в SQLite в папке `data/`. Интернет нужен только Docker для первой сборки контейнера. После запуска сайт открывается на `http://localhost:3000`.

## Запуск в Windows

1. Установи Docker Desktop и дождись, пока он запустится.
2. Распакуй архив в обычную папку, например `C:\PismoDeduMoroz`.
3. Дважды щёлкни `start.bat`.
4. Войди с логином `admin` и выданным отдельно паролем.
5. Чтобы выключить приложение, запусти `stop.bat`.

На первом старте Docker скачает базовый образ и соберёт контейнер. Последующие запуски используют уже собранный образ.

## Учётные записи и доступ

- Первый аккаунт `admin` создаётся автоматически при первом запуске.
- В панели «Участники и доступ» организатор создаёт участникам логины и пароли.
- Для каждой пары настраиваются отдельные права: смотреть список и предлагать подарки.
- Участник добавляет желания только в собственный список. Желания можно убрать в личный архив, вернуть из него или удалить навсегда. Архивные записи видит только владелец; у остальных участников они сразу исчезают. Пароли в базе не хранятся в открытом виде.
- У любого участника есть вкладка «Идеи и отзывы»: общие комментарии и предложения можно искать, фильтровать по типу, сортировать и убирать в личный архив. Организатор видит общий архив и может вернуть запись.
- Участник с доступом к чужому желанию может отметить, что готов его подарить. Все видят только число отметок и собственную отметку; имена участников видит только организатор. Для одного желания отметку могут поставить несколько человек.
- В матрице доступа можно перетаскиванием менять ширину столбцов и высоту строк. Размеры сохраняются в базе для аккаунта организатора; кнопка «Вернуть исходный вид» сбрасывает их.
- Если удалить папку `data/`, будут удалены участники, списки, предложения и настройки доступа.

## Журнал доступа и действий

Организатору доступна вкладка «Журнал действий». В ней сохраняются посещения сайта, успешные и неудачные попытки входа, выходы, создание и удаление участников, смена пароля, изменения матрицы доступа, действия с желаниями, идеи для подарков, записи обратной связи и отметки о готовности сделать подарок. Для записей сохраняются ник, дата и время, IP-адрес и строка браузера; пароль и введённые пароли не сохраняются. Есть поиск, фильтры по типу события и датам, сортировка по времени и постраничный просмотр.

Журнал хранится в `data/wishlist.sqlite`. Для Blitz задай в **Environment** переменную `TRUST_PROXY=1`, чтобы приложение использовало адрес посетителя из заголовков доверенного прокси; изменение переменной применяется после перезапуска. Устанавливай это значение, только когда приложение работает за доверенным прокси, например Blitz. Старые события до установки этой версии в журнал не попадут.

## Где хранятся данные

Все данные находятся в `data/wishlist.sqlite`. Новые таблицы для отзывов, отметок о подарках и размеров матрицы создаются автоматически в существующей базе. Перед обновлением на Blitz сохрани резервную копию и убедись, что папка `/app/data` добавлена в список файлов, которые Blitz сохраняет при перезапуске и выпуске новой версии. Для локальной резервной копии сначала нажми `stop.bat`, скопируй папку `data`, затем снова запусти приложение. Не отправляй папку `data` в общий чат или публичное облако.

По умолчанию сайт привязан только к `localhost`, поэтому другие устройства не смогут открыть его по сети. Не открывай порт 3000 в интернет напрямую. Для внешнего доступа понадобится отдельная настройка HTTPS и обратного прокси; сейчас версия рассчитана на работу на одном компьютере.

## Смена первичного пароля

Пароль первого администратора задан в скрытом файле `.env`. Если сменить его до первого запуска, будет создан аккаунт с новым паролем. После создания базы изменение `.env` не меняет уже сохранённый пароль.
